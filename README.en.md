# PDFCrate

Free PDF tools that run **entirely in your web browser**. Your files are never uploaded to a server — everything is processed on your own device.

**Use it right away, no installation:** https://andrian219.github.io/PDFCrate/

**Interface language:** tap the **EN / ID** button in the top-right corner to switch between English and Indonesian. Your choice is remembered on your device.

## Tools

1. **Word to PDF** — convert a .docx document into a PDF.
2. **Photos to PDF** — turn one or more photos into a single PDF (quality is adjustable).
3. **Merge PDF** — combine several PDF files into one.
4. **PDF to Photos** — save PDF pages as images.
5. **Organize PDF** — reorder, rotate, or delete pages.
6. **Shrink Photos** — reduce photo file sizes, downloaded as a ZIP.

## How to run it yourself

- **Easiest:** open the live site above and just use it.
- **Offline copy:** download `index.html` from this repository and open it in any modern browser.
- **Host it yourself:** upload `index.html` to any static hosting (GitHub Pages, Cloudflare Pages, Netlify, and so on).

One note: the page loads its code libraries from a CDN, so it needs an internet connection when it opens. Your documents are still processed locally on your device and are never sent anywhere.
