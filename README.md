# PDFCrate

Free PDF tools that run **entirely in your web browser**. Your files are never uploaded to a server — everything is processed on your own device.

**Use it right away, no installation:** https://andrian219.github.io/pdfcrate/

**Interface language:** tap the **EN / ID** button in the top-right corner to switch between English and Indonesian. Your choice is remembered on your device.

## Tools

1. **Word to PDF** — convert a .docx document into a PDF.
2. **Photos to PDF** — turn one or more photos into a single PDF (quality is adjustable).
3. **Merge PDF** — combine several PDF files into one.
4. **PDF to Photos** — save PDF pages as images.
5. **Organize PDF** — reorder, rotate, or delete pages.
6. **Shrink Photos** — reduce photo file sizes, downloaded as a ZIP.

## How to run it yourself

- **Easiest:** open the live site above and just use it.
- **Offline copy:** download `index.html` from this repository and open it in any modern browser.
- **Host it yourself:** upload `index.html` to any static hosting (GitHub Pages, Cloudflare Pages, Netlify, and so on).

One note: the page loads its code libraries from a CDN, so it needs an internet connection when it opens. Your documents are still processed locally on your device and are never sent anywhere.

# PDFCrate (Bahasa Indonesia)

Kumpulan alat PDF gratis yang berjalan **sepenuhnya di browser**. Berkasmu tidak pernah diunggah ke server — semua diproses di perangkatmu sendiri.

**Langsung pakai, tanpa memasang apa pun:** https://andrian219.github.io/pdfcrate/

**Bahasa tampilan:** ketuk tombol **EN / ID** di pojok kanan atas untuk berganti antara Bahasa Inggris dan Bahasa Indonesia. Pilihanmu tersimpan di perangkatmu.

## Alat-alatnya

1. **Word jadi PDF** — mengubah dokumen .docx menjadi PDF.
2. **Foto jadi PDF** — menjadikan satu atau banyak foto satu berkas PDF (kualitas bisa diatur).
3. **Gabung PDF** — menggabungkan beberapa berkas PDF menjadi satu.
4. **PDF jadi Foto** — menyimpan halaman PDF sebagai gambar.
5. **Atur Halaman PDF** — mengurutkan ulang, memutar, atau menghapus halaman.
6. **Kecilkan Foto** — mengecilkan ukuran berkas foto, diunduh sebagai ZIP.

## Cara menjalankannya sendiri

- **Paling gampang:** buka situs langsung di atas dan pakai saja.
- **Salinan di perangkat:** unduh berkas `index.html` dari repositori ini, lalu buka di browser apa pun.
- **Pasang di hosting sendiri:** unggah `index.html` ke hosting statis mana pun (GitHub Pages, Cloudflare Pages, Netlify, dan sebagainya).

Satu catatan: halaman ini memuat pustaka kodenya dari CDN, jadi perlu internet saat dibuka. Dokumenmu tetap diproses secara lokal di perangkatmu dan tidak dikirim ke mana pun.
