# PDFCrate

Kumpulan alat PDF gratis yang berjalan **sepenuhnya di browser**. Berkas Anda tidak pernah diunggah ke server — semua diproses di perangkat Anda sendiri.

**Langsung pakai, tanpa memasang apa pun:** https://andrian219.github.io/PDFCrate/

**Bahasa tampilan:** ketuk tombol **EN / ID** di pojok kanan atas untuk berganti antara Bahasa Inggris dan Bahasa Indonesia. Pilihan Anda tersimpan di perangkat Anda.

## Alat-alatnya

1. **Word jadi PDF** — mengubah dokumen .docx menjadi PDF.
2. **Foto jadi PDF** — menjadikan satu atau banyak foto satu berkas PDF (kualitas dapat diatur).
3. **Gabung PDF** — menggabungkan beberapa berkas PDF menjadi satu.
4. **PDF jadi Foto** — menyimpan halaman PDF sebagai gambar.
5. **Atur Halaman PDF** — mengurutkan ulang, memutar, atau menghapus halaman.
6. **Kecilkan Foto** — mengecilkan ukuran berkas foto, diunduh sebagai ZIP.

## Cara menjalankannya sendiri

- **Paling mudah:** buka situs langsung di atas dan pakai saja.
- **Salinan di perangkat:** unduh berkas `index.html` dari repositori ini, lalu buka di browser apa pun.
- **Pasang di hosting sendiri:** unggah `index.html` ke hosting statis mana pun (GitHub Pages, Cloudflare Pages, Netlify, dan sebagainya).

Satu catatan: halaman ini memuat pustaka kodenya dari CDN, jadi perlu internet saat dibuka. Dokumen Anda tetap diproses secara lokal di perangkat Anda dan tidak dikirim ke mana pun.
